# Dati del sito RYO

Il sito (`../index.html`) usa direttamente i file di questa cartella.

| Cartella          | Contenuto |
|-------------------|-----------|
| `logo/`           | Logo RYO ritagliato (PNG trasparente) e favicon |
| `foto/locale/`    | Sala e bancone |
| `foto/drink/`     | Cocktail |
| `foto/cucina/`    | Piatti e post "Nuovo menu" |
| `foto/eventi/`    | Serate, DJ set |
| `foto/galleria/`  | Altre foto d'atmosfera |
| `menu/menu.txt`   | Drink e piatti con prezzi (da compilare) |
| `testi/info.txt`  | Dati del locale (✔ confermati, ✎ da completare) |

Le foto attuali sono ritagliate dagli screenshot di Instagram (@ryococktailbar).
Per una qualità migliore, sostituiscile con gli originali del fotografo usando lo **stesso nome file**:
il sito si aggiornerà da solo.
