# Dati del sito RYO

Metti qui tutto il materiale del locale. Io lo userò per aggiornare il sito.

## foto/
| Cartella    | Cosa metterci |
|-------------|---------------|
| `hero/`     | 1–3 foto d'impatto per l'apertura (bancone o sala di sera, in orizzontale) |
| `locale/`   | Interni, esterno, dehors |
| `drink/`    | Foto dei cocktail (meglio se il nome del file è il nome del drink, es. `negroni.jpg`) |
| `eventi/`   | DJ set, serate, locandine |
| `galleria/` | Altre foto belle per la galleria |

Formati: JPG o PNG, meglio se sopra i 1500 px di larghezza.

## menu/
La drink list: foto del menu, PDF, oppure compila `menu.txt` (una riga per drink: nome · ingredienti · prezzo).

## testi/
Compila `info.txt` con i dati del locale.
